How to read thisCómo leer esto

Every snippet assumes these declarations, so they are not repeated:

Grid   PropGridClass            ! or your own derived class
Cat    SIGNED                   ! a category id
Row    SIGNED                   ! a row id
Fnt    SIGNED                   ! a font id
Win    WINDOW('Demo'),AT(,,320,240),GRAY,SYSTEM,TIMER(10)
         REGION,AT(4,4,312,232),USE(?PGRegion)
       END
ConventionMeaning
,PROC on a methodIt returns something you are allowed to ignore, so it can be called as a statement.
,VIRTUALYou can override it in a derived class. Ten methods are.
A * parameterPassed by reference — the method writes into your variable.
IdsRows, categories and fonts are small positive integers. Keep the ones you will need again; 0 always means "none" or "inherit".
Nothing works before Init. Every method starts with a "is the grid alive?" check and returns quietly if it is not, so a call in the wrong place fails silently rather than crashing. If a call seems to do nothing, check Initialized first.

Todos los fragmentos dan por hecho estas declaraciones, así que no se repiten:

Grid   PropGridClass            ! o su propia clase derivada
Cat    SIGNED                   ! un id de categoría
Row    SIGNED                   ! un id de fila
Fnt    SIGNED                   ! un id de fuente
Win    WINDOW('Demo'),AT(,,320,240),GRAY,SYSTEM,TIMER(10)
         REGION,AT(4,4,312,232),USE(?PGRegion)
       END
ConvenciónSignificado
,PROC en un métodoDevuelve algo que usted puede ignorar, así que se puede llamar como sentencia.
,VIRTUALSe puede sobrescribir en una clase derivada. Diez métodos lo son.
Un parámetro *Va por referencia — el método escribe en su variable.
IdsFilas, categorías y fuentes son enteros positivos pequeños. Guarde los que vaya a volver a necesitar; 0 siempre significa "ninguno" o "heredar".
Nada funciona antes de Init. Todo método empieza con una comprobación de "¿está viva la rejilla?" y vuelve en silencio si no lo está, así que una llamada en el sitio equivocado falla sin ruido en vez de reventar. Si una llamada parece no hacer nada, mire primero Initialized.

Properties you setPropiedades que usted fija

Plain class fields — assign them directly. All of them are read at a particular moment, so when you set them matters; each entry says when.

LiveSync BYTE · default 0

Read by TakeChanged, on every edit.

1 = every keystroke that commits is pushed straight into the control's USE variable. 0 = nothing is written until you call SyncBack.

Grid.LiveSync = 1                ! edits land in the USE vars immediately
! with 0, call Grid.SyncBack() on your OK button instead
HideOriginals BYTE · default 1

Read by BuildFromWindow, as each row is created.

1 = a converted control and the PROMPT that labels it are hidden. 0 = the form stays visible with the grid beside it, which is useful while you are checking the conversion.

Grid.HideOriginals = 0           ! see both, side by side, while debugging
Grid.BuildFromWindow(Cat)
TimerInterval SIGNED · default 10

Read by InitXY, once.

Hundredths of a second. Applied to the window only if it has no timer of its own. 0 leaves the window completely alone — then pumping TakeEvent is your job.

Grid.TimerInterval = 5           ! 20 ticks a second, before Init
Grid.Init(Win, ?PGRegion)
! Grid.TimerInterval = 0   ! do not touch the window's timer at all
TabCategories BYTE · default 0

Read by BuildFromWindow, per row.

1 = each TAB's own text becomes a category and its controls land under it. 0 = everything goes to the category you passed in.

Grid.TabCategories = 1           ! before BuildFromWindow
Grid.BuildFromWindow(Cat)        ! Cat is now only the fallback
MaxScanItems SIGNED · default 500

Read whenever a queue-driven DROP is enumerated.

The cap on walking a LIST/COMBO's items to read its choices. Raise it for a long drop-down, lower it if a huge list makes conversion slow.

Grid.MaxScanItems = 2000         ! a long state/country drop-down
DockMode BYTE · DockSize SIGNED · MarginX / MarginY SIGNED

Read by Reposition, every time.

Set them together with SetDock rather than by hand — see SetDock. Assigning them directly works and is occasionally handy:

Grid.DockMode = PGD:Right          ! same as SetDock(PGD:Right, 300, 4, 4)
Grid.DockSize = 300
Grid.MarginX  = 4
Grid.MarginY  = 4
Grid.Reposition()
Style ULONG · default PGS:Border + PGS:Description

Read by InitXY, once.

Only what you pass to Init actually reaches the DLL; this field records it. Changing it afterwards does nothing — destroy and re-init to change the style.

Grid.Init(Win, ?PGRegion, PGS:Border + PGS:Sort)   ! no description pane

Campos de clase normales — asígnelos directamente. Todos se leen en un momento concreto, así que cuándo los fija importa; cada entrada lo dice.

LiveSync BYTE · defecto 0

Lo lee TakeChanged, en cada edición.

1 = cada edición confirmada se escribe de inmediato en la variable USE del control. 0 = no se escribe nada hasta que usted llame a SyncBack.

Grid.LiveSync = 1                ! las ediciones caen ya en las variables USE
! con 0, llame a Grid.SyncBack() en su botón OK
HideOriginals BYTE · defecto 1

Lo lee BuildFromWindow, al crear cada fila.

1 = el control convertido y el PROMPT que lo etiqueta se ocultan. 0 = el formulario sigue visible con la rejilla al lado, útil mientras revisa la conversión.

Grid.HideOriginals = 0           ! ver los dos, lado a lado, al depurar
Grid.BuildFromWindow(Cat)
TimerInterval SIGNED · defecto 10

Lo lee InitXY, una vez.

Centésimas de segundo. Se aplica a la ventana sólo si no tiene timer propio. 0 no toca la ventana — entonces bombear TakeEvent es cosa suya.

Grid.TimerInterval = 5           ! 20 ticks por segundo, antes de Init
Grid.Init(Win, ?PGRegion)
! Grid.TimerInterval = 0   ! no tocar el timer de la ventana
TabCategories BYTE · defecto 0

Lo lee BuildFromWindow, por fila.

1 = el texto de cada TAB se vuelve categoría y sus controles caen debajo. 0 = todo va a la categoría que usted pasó.

Grid.TabCategories = 1           ! antes de BuildFromWindow
Grid.BuildFromWindow(Cat)        ! Cat pasa a ser sólo el respaldo
MaxScanItems SIGNED · defecto 500

Se lee al enumerar un DROP servido por cola.

El tope al recorrer los elementos de un LIST/COMBO para leer sus opciones. Súbalo para un desplegable largo, bájelo si una lista enorme hace lenta la conversión.

Grid.MaxScanItems = 2000         ! un desplegable largo de estados/países
DockMode BYTE · DockSize SIGNED · MarginX / MarginY SIGNED

Los lee Reposition, siempre.

Fíjelos juntos con SetDock y no a mano — vea SetDock. Asignarlos directamente funciona y a veces viene bien:

Grid.DockMode = PGD:Right          ! igual que SetDock(PGD:Right, 300, 4, 4)
Grid.DockSize = 300
Grid.MarginX  = 4
Grid.MarginY  = 4
Grid.Reposition()
Style ULONG · defecto PGS:Border + PGS:Description

Lo lee InitXY, una vez.

Sólo lo que pasa a Init llega de verdad a la DLL; este campo lo registra. Cambiarlo después no hace nada — destruya y vuelva a inicializar para cambiar el estilo.

Grid.Init(Win, ?PGRegion, PGS:Border + PGS:Sort)   ! sin panel de descripción

Properties you readPropiedades que usted lee

Initialized BYTE

1 between a successful Init and Kill.

The one property worth testing routinely. The generated templates guard their whole build block with it.

IF Grid.Init(Win, ?PGRegion)
  ! ... build the grid ...
END
! or later, from anywhere:
IF Grid.Initialized
  Grid.SetValue(Row, 'safe to call')
END
Win &WINDOW

The window Init was given, held by reference.

Useful in a derived method that needs the window without taking it as a parameter. Do not reassign it.

MyGrid.TakeSelect PROCEDURE(SIGNED row)
  CODE
  SETTARGET(SELF.Win)             ! the owning window
  ?Status{PROP:Text} = 'Row ' & row
  SETTARGET()
RegionFeq SIGNED

The placeholder REGION Init was given; 0 after InitXY.

IF Grid.RegionFeq
  UNHIDE(Grid.RegionFeq)          ! it is a real control on your window
END
PG LONG

The raw HPG handle; 0 = no grid.

Only needed if you want to call a DLL function the class does not wrap. Prefer Initialized for "is it alive".

IF Grid.PG
  PG_GetHwnd(Grid.PG)            ! straight to the flat API
END
Initialized BYTE

1 entre un Init exitoso y Kill.

La única propiedad que conviene comprobar de rutina. Las plantillas generadas protegen con ella todo su bloque de construcción.

IF Grid.Init(Win, ?PGRegion)
  ! ... construir la rejilla ...
END
! o después, desde donde sea:
IF Grid.Initialized
  Grid.SetValue(Row, 'seguro de llamar')
END
Win &WINDOW

La ventana que recibió Init, por referencia.

Útil en un método derivado que necesita la ventana sin recibirla como parámetro. No la reasigne.

MyGrid.TakeSelect PROCEDURE(SIGNED row)
  CODE
  SETTARGET(SELF.Win)             ! la ventana dueña
  ?Status{PROP:Text} = 'Fila ' & row
  SETTARGET()
RegionFeq SIGNED

El REGION marcador que recibió Init; 0 tras InitXY.

IF Grid.RegionFeq
  UNHIDE(Grid.RegionFeq)          ! es un control real de su ventana
END
PG LONG

El handle HPG crudo; 0 = sin rejilla.

Sólo hace falta si quiere llamar a una función de la DLL que la clase no envuelve. Para "¿está viva?" use Initialized.

IF Grid.PG
  PG_GetHwnd(Grid.PG)            ! directo a la API plana
END

The internal onesLas internas

These exist because the class needs them across calls. Read them if you are debugging; write them only if you are extending the class and know why.

Lifetime & placementVida y colocación

Init PROCEDURE(WINDOW W, SIGNED regionFeq, ULONG style=3), BYTE, PROC, VIRTUAL

Create the grid over a REGION control. Returns 1 on success.

IF Grid.Init(Win, ?PGRegion, PGS:Border + PGS:Description)
  ! the grid now tracks ?PGRegion on every resize
ELSE
  MESSAGE('PROPGRID.DLL did not create the grid.')
END
InitXY PROCEDURE(WINDOW W, SIGNED x, y, width, height, ULONG style=3), BYTE, PROC, VIRTUAL

Create it at fixed pixel coordinates instead, with no REGION.

Grid.InitXY(Win, 4, 4, 300, 400, PGS:Border)
Grid.SetDock(PGD:Right, 300, 4, 4)   ! then tell it how to follow a resize
Kill PROCEDURE(), VIRTUAL

Destroy the grid. Idempotent — calling it twice is harmless.

Grid.Kill()
CLOSE(Win)
SetDock PROCEDURE(BYTE mode, SIGNED size=0, marginX=0, marginY=0)

Decide what Reposition does. Only needed after InitXY — Init sets PGD:Region for you.

Grid.SetDock(PGD:Right, 300, 4, 4)   ! 300px down the right edge
Grid.SetDock(PGD:Fill, 0, 8, 8)      ! whole client area, 8px inset
Grid.SetDock(PGD:Fixed)               ! never move it again
SetPos PROCEDURE(SIGNED x, y, width, height)

Move it now, in pixels, ignoring the dock mode.

Grid.SetPos(4, 4, 320, 500)      ! absolute, right now
Reposition PROCEDURE(), VIRTUAL

Re-apply the dock / re-track the REGION. Call it from EVENT:Sized.

OF EVENT:Sized
  Grid.Reposition()
In an ABC window, POST a private event first. At the top of TakeWindowEvent the ABC resizer has not moved the REGION yet, so its width is still the old one. That is why the templates do OF EVENT:Sized ; POST(PGResize:Obj) and reposition when that arrives.
Construct / Destruct PROCEDURE()

Called by Clarion, never by you.

Construct sets the factory defaults and NEWs the three registries; Destruct kills the grid if you forgot and disposes them. Worth knowing they exist so you do not double-free.

Init PROCEDURE(WINDOW W, SIGNED regionFeq, ULONG style=3), BYTE, PROC, VIRTUAL

Crear la rejilla sobre un control REGION. Devuelve 1 si va bien.

IF Grid.Init(Win, ?PGRegion, PGS:Border + PGS:Description)
  ! la rejilla ya sigue a ?PGRegion en cada redimensión
ELSE
  MESSAGE('PROPGRID.DLL no creó la rejilla.')
END
InitXY PROCEDURE(WINDOW W, SIGNED x, y, width, height, ULONG style=3), BYTE, PROC, VIRTUAL

Crearla en coordenadas fijas de píxeles, sin REGION.

Grid.InitXY(Win, 4, 4, 300, 400, PGS:Border)
Grid.SetDock(PGD:Right, 300, 4, 4)   ! y dígale cómo seguir una redimensión
Kill PROCEDURE(), VIRTUAL

Destruir la rejilla. Idempotente — llamarlo dos veces es inofensivo.

Grid.Kill()
CLOSE(Win)
SetDock PROCEDURE(BYTE mode, SIGNED size=0, marginX=0, marginY=0)

Decidir qué hace Reposition. Sólo hace falta tras InitXY — Init pone PGD:Region por usted.

Grid.SetDock(PGD:Right, 300, 4, 4)   ! 300px por el borde derecho
Grid.SetDock(PGD:Fill, 0, 8, 8)      ! toda el área cliente, 8px de margen
Grid.SetDock(PGD:Fixed)               ! que no se mueva más
SetPos PROCEDURE(SIGNED x, y, width, height)

Moverla ya, en píxeles, ignorando el modo de acople.

Grid.SetPos(4, 4, 320, 500)      ! absoluto, ahora mismo
Reposition PROCEDURE(), VIRTUAL

Reaplicar el acople / volver a seguir al REGION. Llámelo desde EVENT:Sized.

OF EVENT:Sized
  Grid.Reposition()
En una ventana ABC, haga POST de un evento privado primero. Al principio de TakeWindowEvent el redimensionador de ABC todavía no movió el REGION, así que su ancho sigue siendo el viejo. Por eso las plantillas hacen OF EVENT:Sized ; POST(PGResize:Obj) y recolocan cuando llega ese.
Construct / Destruct PROCEDURE()

Los llama Clarion, nunca usted.

Construct pone los valores de fábrica y hace NEW de los tres registros; Destruct mata la rejilla si se le olvidó y los libera. Conviene saber que existen para no liberar dos veces.

SetFont PROCEDURE(SHORT part, STRING face, SHORT sizePt, BYTE bold=0, BYTE italic=0)

One of the four global font slots. This is the normal way to style a grid.

Grid.SetFont(PGF:Name,     'Segoe UI', 9, 0, 0)
Grid.SetFont(PGF:Value,    'Segoe UI', 9, 0, 0)
Grid.SetFont(PGF:Category, 'Segoe UI', 9, 1, 0)   ! bold headers
Grid.SetFont(PGF:Desc,     'Segoe UI', 8, 0, 1)   ! italic description pane
SetColor PROCEDURE(SHORT slot, LONG color)

One of the eleven colour slots. Clarion colours are 0BBGGRRh.

Grid.SetColor(PGC:CatBack,   00E4E9F0h)   ! reads blue-green-red!
Grid.SetColor(PGC:CatText,   005F3A1Fh)   ! = RGB 1F3A5F, steel blue
Grid.SetColor(PGC:SelBack,   COLOR:HighLight)
Grid.SetColor(PGC:ValueText, COLOR:Black)

SetSplitter PROCEDURE(SHORT px)

Width of the name column. The user can still drag it afterwards.

SyncingSincronización

SyncBack PROCEDURE()

Every row → its control's USE variable. This is the one you call on OK.

OF ?OkBtn
  Grid.SyncBack()                ! the whole grid, into the form
  ! CUS:Name, CUS:Active ... are now current
With LiveSync off, nothing writes back until this runs. If your window has no OK button, either turn LiveSync on or call this yourself.
SyncRow PROCEDURE(SIGNED row)

One row → its control. What TakeChanged calls when live sync is on.

Grid.SyncRow(Grid.GetSelected()) ! push just the row being edited
SyncFrom PROCEDURE()

The other direction: every control → its row, then repaint. Call it after anything changes the form behind the grid's back.

CUS:DeptCode = 'D04'              ! your own code changed a USE variable
Grid.SyncFrom()                  ! the grid now shows 'Head office'
A lookup row round-trips through its code. SyncFrom reads the hidden code control and shows the matching name; SyncBack takes the name the user picked and writes the code. An unknown code is shown raw rather than blanked.
SyncBack PROCEDURE()

Cada fila → la variable USE de su control. Es la que se llama en OK.

OF ?OkBtn
  Grid.SyncBack()                ! toda la rejilla, al formulario
  ! CUS:Name, CUS:Active ... ya están al día
Con LiveSync apagado, nada se escribe hasta que esto corra. Si su ventana no tiene botón OK, encienda LiveSync o llámelo usted.
SyncRow PROCEDURE(SIGNED row)

Una fila → su control. Lo que llama TakeChanged con la sincronización viva encendida.

Grid.SyncRow(Grid.GetSelected()) ! empujar sólo la fila que se edita
SyncFrom PROCEDURE()

La dirección contraria: cada control → su fila, y repintar. Llámelo tras cualquier cosa que cambie el formulario a espaldas de la rejilla.

CUS:DeptCode = 'D04'              ! su código cambió una variable USE
Grid.SyncFrom()                  ! la rejilla ya muestra 'Oficina central'
Una fila de búsqueda va y vuelve por su código. SyncFrom lee el control de código oculto y muestra el nombre correspondiente; SyncBack toma el nombre que eligió el usuario y escribe el código. Un código desconocido se muestra tal cual.
